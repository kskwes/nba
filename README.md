# NBA Daily

NBA の試合結果・順位・選手やチームの成績を、日本語の解説つきでまとめて見るための個人用サイトです。

**サイト:** https://kskwes.github.io/nba/games/

- 試合・成績・順位などは、開いたときに ESPN の公開データから取得します。
- 分析データ・年俸・ドラフト指名権は、ファイルとして持っていて手動で更新します（[データ](#データ)を参照）。
- 日時は日本時間で表示します。
- スマホでも PC でも見られます。
- 個人用のため、検索エンジンには載せていません。

## ページ

### Games（試合）
`games/`

| タブ | 内容 |
|---|---|
| Schedule | 今日・明日・昨日の試合カード（スコア、成績、各チームの得点リーダー）。終わった試合には見どころのラベル（名勝負 / 接戦 / 見どころあり / 一方的）、NBA カップの試合にはバッジが付く。今日の怪我人一覧 |
| Top 10 Players | その日の活躍上位10人。ルーキー・2年目だけの絞り込みもある |

### 試合ページ
`games/game.html?id=<ESPN の試合ID>`

試合前は Preview タブだけ、試合中・終了後は下の6つのタブになります。終わった試合では、スコアの下に見どころのラベルと理由（延長・終盤まで接戦など）を出します。

| タブ | 内容 |
|---|---|
| Preview（試合前） | 注目ポイント、ESPN の勝率予測、両チームの成績と比較、直近の試合、今季の対戦、リーダー、怪我人 |
| Box Score | ボックススコア（クォーター別にも切り替え）と、得点の取り方・使われ方と効率・Game Score の内訳・クォーター別の得点のグラフ。試合中は、コートにいる5人の名前の前に赤い点 |
| Team Stats | 両チームの比較（Four Factors、ベンチの得点など） |
| Impact | 勝率を動かしたプレー（WPA）と Clutch の時間の成績 |
| Shots | ゾーン別の成功率とシュートチャート |
| Flow | 得点の推移、連続得点と無得点の時間、勝負の分かれ目、タイムアウト直後の攻撃の結果 |
| Rotation | 選手ごとの出場時間帯と、そのときの得失点、5人の組み合わせ |

### Standings（順位）
`standings/`

| タブ | 内容 |
|---|---|
| Standings | カンファレンス別の順位表とドラフトのロッタリー |
| Playoffs / Play-In | プレーオフの組み合わせとシリーズの結果 |
| Draft | 直近のドラフトの指名結果と、指名された選手の今の所属。ドラフト当日は指名の進み具合を表示する |

### Players（選手）
`players/`

| タブ・ページ | 内容 |
|---|---|
| Players | 選手の検索とルーキーの一覧 |
| Leaders | 今季の部門別ランキング |
| 選手ページ（`player.html?id=`） | プロフィール、今季の成績、直近の試合の推移と、Player Profile（下記） |

**Player Profile** は、次をまとめたものです。
- 効率と役割: TS%・eFG%・USG%・AST%・TOV%・REB% のリーグ順位
- 使われ方と効率: リーグ全体の中での位置を示す散布図
- シュートの傾向: ゾーン別に、リーグ平均と比べたもの
- Game Score の安定度
- On/Off

順位と散布図の対象は、出場時間が「所属チームの試合数 × 20分」以上の選手です。

### Teams（チーム）
`teams/`

| タブ・ページ | 内容 |
|---|---|
| Teams | リーグ全体のチームスタッツの表と、チーム一覧 |
| Advanced | リーグ全体の On/Off、5人の組み合わせ（ラインナップ）、チームのスタイルマップ、ハーフコートと速攻の攻守、選手の使われ方と効率、Clutch の成績 |
| チームページ（`team.html?team=<略称>`） | 今季の成績、Team Style（下記）、ロスターの成績、このチームの Advanced、Assist Map（下記）、日程、怪我人、相手チーム別の対戦成績 |

**Team Style** は、次をまとめたものです。
- 戦い方の型: PACE、3P・ゴール下・ミドルの割合、FT、速攻の得点
- スタイルマップ
- 攻守の強み・弱み（Four Factors）
- ハーフコートと速攻の攻守

**Assist Map** は、誰が誰にアシストしているかを示します。
- 名コンビの上位3組（2人が一緒にコートにいるときの得失点差つき）
- 選手ごとのパスの行き先の図
- 今季 / 直近5試合の切り替え

### Salary（年俸）
`salary/`

| 内容 |
|---|
| 全体のサマリー、チーム別・選手別のサラリーとサラリーキャップとの比較、契約の種類ごとの内訳、各チームが持つ2027〜2033年のドラフト指名権 |

### Predict（予想）
`predict/`

| タブ | 内容 |
|---|---|
| Season / Playoffs | シーズン前に入力した順位・プレーオフ・アワードの予想と、実際の結果との比べ |
| Trends | 毎週日曜時点の順位の推移（カンファレンス別。チームを選んで比べられる） |

予想はブラウザに下書きとして保存され、書き出したファイル（`data/predictions-<シーズン>.js`）を置くと表示専用になります。

## データ

| 何のデータか | どこから | 更新 |
|---|---|---|
| 試合・成績・順位・ロスター・怪我人など | ESPN の公開 API | ページを開いたときに取得（ブラウザに一時保存） |
| 分析データ（`data/advanced.json`、`data/assists.json`） | ESPN の試合ごとの記録（play-by-play）を集計 | 手動 |
| 年俸（`data/salaries.js`） | Over the Apron（Hoops Nightly・ESPN と照合） | 手動 |
| ドラフト指名権（`data/draft-picks.js`） | Over the Apron（Hoops Nightly と照合） | 手動 |

分析データは次の内容です。On/Off、ラインナップ、Clutch、Player Profile、Team Style、ハーフコートと速攻、Assist Map。

- 集計日時はページに表示され、7日以上たつと注意の色になります。
- ポゼッションは play-by-play から実際に数えていて、NBA.com の OffRtg と一致することを確かめてあります。
- 速攻は、攻撃の始まりから6秒以内にシュート・FT・TO があった攻撃です。ESPN の速攻の得点と平均がそろうことを確かめて、6秒に決めました。

手動のデータは、試合の取得と集計のスクリプトを手元で動かして作り、できたファイルをこのリポジトリにアップロードします。スクリプトと試合の保存データは、このリポジトリには入れていません。

## フォルダ

```
assets/      共通のスクリプト・スタイル・アイコン
data/        手動で更新するデータ
games/       Games と試合ページ
standings/   Standings・Playoffs・Draft
players/     Players と選手ページ
teams/       Teams と チームページ
salary/      Salary
predict/     Predict
index.html   games/ への転送（旧 URL 用）
```

`assets/` を変えたときは、各ページの読み込みの `?v=` を上げて、ブラウザに古いファイルが残らないようにしています。
